# Direction AE: 工作流模板市场

## 1. 目标

为 hermes-agent-collab 提供工作流模板市场，支持预定义工作流模板的发布、发现、安装和版本管理，降低团队协作的学习成本。

## 2. 背景

当前系统（Direction AD）支持审计日志，但工作流编排（Direction C）需要用户手动创建。协作场景中需要：
- 模板共享：团队可以发布可复用的工作流模板
- 模板发现：浏览、搜索、安装他人分享的模板
- 版本管理：模板的版本迭代和兼容性管理
- 评分反馈：用户可以对模板评分

### 3.2 核心组件

#### 3.2.1 template_market.py

```python
class WorkflowTemplate:
    """Represents a publishable workflow template."""
    
    template_id: str
    name: str
    workflow: dict
    version: str
    category: str
    
class TemplateMarket:
    """Template registry with search, install, rate, publish."""
    
    def publish(self, template: WorkflowTemplate) -> str:
        """Publish a template to the market."""
    
    def discover(self, category: str | None, tags: list[str], 
                 query: str | None, page: int) -> list[TemplateListing]:
        """Discover templates."""
    
    def install(self, template_id: str, workspace_id: str) -> str:
        """Install template to workspace (returns workflow_id)."""
    
    def rate(self, template_id: str, user_id: str, rating: float):
        """Rate a template (1-5)."""
    
    def get_version(self, template_id: str) -> str:
        """Get latest version."""
```

#### 3.2.2 模板市场 API

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /templates/publish | 发布模板 |
| GET | /templates | 发现模板（分页、过滤） |
| GET | /templates/{id} | 获取模板详情 |
| POST | /templates/{id}/install | 安装模板到 workspace |
| POST | /templates/{id}/rate | 评分 |
| GET | /templates/categories | 列出所有分类 |

### 3.3 关键设计

- 本地存储：模板元数据存储在 `~/.hermes/collab/templates/` JSON 文件
- 远程模板：支持 HTTP URL 模板（从远程 JSON URL 安装）
- 分类体系：development, testing, deployment, monitoring, custom
- 版本语义：semver，支持 `min_app_version` 约束
- 评分系统：滑动窗口平均评分
