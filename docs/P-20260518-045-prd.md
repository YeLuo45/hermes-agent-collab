# Direction AB: gRPC 接口

## 1. 目标

为 hermes-agent-collab 提供 gRPC 接口，与现有 REST API 并存，用于高性能、低延迟场景（内部服务通信、实时流式处理）。

## 2. 背景

当前系统（Direction AA）提供 REST API + SSE，适合浏览器客户端和外部集成。协作场景中需要：
- 高性能内部服务间通信（比 REST 低 3-10 倍延迟）
- 双向流式 RPC（实时任务状态推送、Agent 心跳）
- 协议缓冲区 Schema 定义的强类型 API（代码生成、跨语言）
- 与 REST API 共用同一业务逻辑层

## 3. 功能范围

### 3.1 核心功能

#### 3.1.1 Protocol Buffer Schema

```protobuf
syntax = "proto3";
package hermes.collab.v1;

service CollaborationService {
  // Workspace
  rpc CreateWorkspace(CreateWorkspaceRequest) returns (Workspace);
  rpc GetWorkspace(GetWorkspaceRequest) returns (Workspace);
  rpc ListWorkspaces(ListWorkspacesRequest) returns (ListWorkspacesResponse);
  
  // Agents
  rpc RegisterAgent(RegisterAgentRequest) returns (Agent);
  rpc GetAgent(GetAgentRequest) returns (Agent);
  rpc ListAgents(ListAgentsRequest) returns (ListAgentsResponse);
  rpc UpdateAgentStatus(UpdateAgentStatusRequest) returns (Agent);
  
  // Tasks
  rpc CreateTask(CreateTaskRequest) returns (Task);
  rpc GetTask(GetTaskRequest) returns (Task);
  rpc ListTasks(ListTasksRequest) returns (ListTasksResponse);
  rpc UpdateTask(UpdateTaskRequest) returns (Task);
  rpc CompleteTask(CompleteTaskRequest) returns (Task);
  
  // Streaming
  rpc StreamEvents(StreamEventsRequest) returns (stream Event);
  rpc ExecuteTaskStream(ExecuteTaskRequest) returns (stream TaskResult);
}
```

### 3.2 改造现有组件

- `collaboration/server.py`：添加 gRPC server 初始化 + 双端口监听
- `collaboration/config.py`：GRPC_* 配置项
- `requirements.txt`：grpcio, grpcio-tools 依赖
- 新增 `collaboration/grpc_server.py`：gRPC servicer 实现
- 新增 `protos/` 目录：`collaboration.proto`, `generate.sh`

### 3.3 关键设计

- gRPC 与 REST 共用同一业务逻辑层（TaskManager, WorkspaceManager 等）
- 使用 `grpcio`（纯 Python 实现，无需编译）
- 认证：gRPC 同样使用 `X-API-Key` 头部或 metadata
- 错误处理：使用 gRPC status codes (NOT_FOUND, ALREADY_EXISTS, etc.)
