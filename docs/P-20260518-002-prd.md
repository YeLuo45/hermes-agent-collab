## 1. Overview / 背景

hermes-agent-collab 当前有基础 Agent Profile，但缺少角色专业化分工和流程控制。参考 ChatDev 的 Role 分工（CEO/CTO/Programmer/Reviewer）和 Phase-Gated Pipeline，引入角色专业化 + 阶段门禁控制。

---

## 2. Goals / 目标

- 引入 Agent Role System：定义 Agent 角色类型（orchestrator/executor/critic/monitor）和职责
- Phase-Gated Pipeline：为复杂任务引入多阶段工作流（Planning → Review → Execution → Done）
- Plan Review Gate：每个阶段完成后需通过 Review 才能进入下一阶段
- TaskComplexity 评估：自动判断任务复杂度路由到不同处理路径
- Role-specific prompts：每个角色有专属 system prompt

---

## 3. Core Features / 核心功能

### 3.1 Agent Role System

```python
class AgentRole(str, Enum):
    ORCHESTRATOR = "orchestrator"   # 任务分配、协调
    EXECUTOR = "executor"          # 具体执行
    CRITIC = "critic"              # 质量审查
    MONITOR = "monitor"            # 进度监控
    SPECIALIST = "specialist"      # 领域专家
```

每个 Agent 有 `role` 字段，决定其能力和行为模式。

### 3.2 Phase-Gated Pipeline

```
PENDING → PLANNING → PLAN_REVIEW → EXECUTING → EXECUTION_REVIEW → DONE
                ↓ Pass               ↓ Pass           ↓ Pass
            Retry/Abort          Retry/Abort      Retry/Abort
```

阶段说明：
- `PENDING`: 任务创建，等待认领
- `PLANNING`: Executor 制定执行计划
- `PLAN_REVIEW`: Critic 审查计划，通过后进入执行
- `EXECUTING`: 执行任务
- `EXECUTION_REVIEW`: Critic 审查结果，通过后完成任务
- `DONE`: 任务完成

### 3.3 Plan Review Gate

```python
@dataclass
class PhaseGate:
    phase: Phase
    approved: bool
    approver_role: AgentRole
    comments: str
    timestamp: datetime
```

- 每个 phase 转换需要对应角色批准
- 被拒绝可返回上一阶段重试或中止

### 3.4 TaskComplexity 评估

```python
def evaluate_complexity(task: Task) -> TaskComplexity:
    # 基于 task title/description/token count/depends_on 评估
    if score < 3: return TaskComplexity.SIMPLE      # 单阶段
    elif score < 7: return TaskComplexity.NORMAL     # 标准流程
    else: return TaskComplexity.COMPLEX              # 多阶段审查
```

路由：
- `SIMPLE`: PENDING → EXECUTING → DONE
- `NORMAL`: 全流程（无 PLAN_REVIEW）
- `COMPLEX`: 全流程 + 强制双审

### 3.5 Role-specific System Prompts

```python
ROLE_PROMPTS = {
```
