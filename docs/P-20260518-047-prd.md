# Direction AD: 审计日志

## 1. 目标

为 hermes-agent-collab 提供不可篡改的只追加审计日志，记录所有关键操作（任务创建/变更/完成、Agent 注册、配置变更、敏感操作等），满足合规和安全审计需求。

## 2. 背景

当前系统（Direction AC）支持配置验证，但所有操作均无持久化日志。协作场景中需要：
- 合规性：追踪谁在何时做了什么操作
- 安全审计：API Key 创建/删除、租户配额变更、Webhook 配置
- 故障排查：操作历史重构
- 防篡改：日志只能追加，不能修改或删除历史记录

## 3. 功能范围

### 3.1 日志条目结构

```json
{
  "event_id": "uuid",
  "timestamp": "ISO8601",
  "actor": {
    "type": "agent|user|system",
    "id": "agent_id or user_id",
    "workspace_id": "workspace_id"
  },
  "action": "task.created|agent.registered|config.updated|...",
  "target": {
    "type": "task|agent|workspace|config|secret",
    "id": "resource_id"
  },
  "changes": {
    "before": {},
    "after": {}
  },
  "metadata": {
    "ip": "client_ip",
    "user_agent": "...",
    "request_id": "uuid"
  }
}
```

### 3.2 核心组件

#### 3.2.1 audit_logger.py

```python
class AuditLogger:
    """Immutable append-only audit log writer."""
    
    def __init__(self, log_dir: Path | None = None, rotation: str = "daily"):
        # File-based append-only log (JSONL)
        # Rotation: daily / size (100MB) / none
    
    def log(self, event: AuditEvent) -> str:
        """Write event, return event_id. Raises on write failure."""
    
    def query(
        self,
        workspace_id: str | None = None,
        actor_id: str | None = None,
        action: str | None = None,
        start_time: datetime | None = None,
        end_time: datetime | None = None,
        limit: int = 100,
    ) -> list[AuditEvent]:
        """Query log entries (read-only scan)."""
```

#### 3.2.2 装饰器自动记录

```python

async def complete_task(task_id: str, result: dict):
    ...
```

#### 3.2.3 集成点

- `collab_api.py`：所有 CRUD 端点自动记录审计日志
- `secret_store.py`：API Key 创建/删除/轮换
- `config_hotreload.py`：配置变更
- `quota_manager.py`：配额变更

### 3.3 关键设计

- 只追加：使用 `a` 模式写入，不支持 `r+` 或 truncate
- JSONL 格式：每行一条 JSON，方便流式读取和外部处理
- 文件名：`audit-{workspace_id}-{YYYYMMDD}.jsonl`
- 索引：`audit_index.jsonl` 按 (workspace_id, date) 指向日志文件
- 保留策略：默认永久保留，可配置 TTL
- 防篡改：可选项计算每行的 SHA-256 哈希（chain hash）
