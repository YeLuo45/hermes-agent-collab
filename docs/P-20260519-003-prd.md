# Direction AN: 仪表盘 / Admin UI

## 1. 目标

为 hermes-agent-collab 提供完整的 Admin 管理仪表盘，基于 Dashboard 模块（Direction O 已实现基础 dashboard/index.html），扩展为全功能管理界面，支持 Agent、Task、Workspace、Quota、Audit 等的可视化管理。

## 2. 背景

当前系统（Direction AM）支持 Redis 缓存，但缺乏统一的管理界面。协作面板需要：
- 全局 Agent 状态监控（在线/离线/忙碌）
- Task 队列和执行状态可视化
- Workspace 资源配置和配额使用
- Audit 日志查询和可视化
- A/B 实验状态和效果图表
- 知识图谱实体关系浏览
- 通知渠道状态管理

## 3. 功能范围

### 3.1 页面结构

```
/dashboard/index.html (已存在，639 行)
├── 侧边导航
│   ├── Overview (总览)
│   ├── Agents (Agent 管理)
│   ├── Tasks (任务队列)
│   ├── Workspaces (工作空间)
│   ├── Quotas (配额管理)
│   ├── Audit (审计日志)
│   ├── Experiments (A/B 实验)
│   ├── Knowledge Graph (知识图谱)
│   ├── Notifications (通知渠道)
│   └── Settings (系统设置)
```

### 3.2 Overview 页面

- **统计卡片**：Agent 总数、在线数、Task 总数、Workspace 数、实验数
- **最近活动**：最新 10 条 Audit 日志
- **A/B 实验状态**：运行中/已停止实验统计
- **缓存状态**：Redis 连接状态、内存使用

### 3.3 Agents 页面

- Agent 列表（名称、状态、角色、Workspace、注册时间）
- 状态筛选（全部/在线/离线/忙碌）
- Agent 详情弹窗
- 批量操作（暂停/恢复/注销）

### 3.4 Tasks 页面

- Task 列表（ID、标题、状态、优先级、创建时间）
- 状态筛选（pending/running/completed/failed）
- Task DAG 可视化（简单依赖图）
- Task 重试操作

### 3.5 Workspaces 页面

- Workspace 列表（名称、Owner、Agent 数量、配额使用）
- 配额使用进度条
- Workspace 创建/编辑

### 3.6 Quotas 页面

- Workspace 配额配置（API 调用限制、存储限制）
- 使用量可视化
- 配额告警阈值配置

### 3.7 Audit 页面

- 审计日志列表（时间、Actor、Action、Target）
- 筛选器（时间范围、Actor 类型、Action 类型）
- 日志详情查看
- 哈希链验证

### 3.8 Experiments 页面

- A/B 实验列表（名称、状态、流量分配、开始时间）
- 实验结果图表（转换率对比、统计显著性）
- 实验创建/停止

### 3.9 Knowledge Graph 页面

- 节点列表（实体类型、名称）
- 关系类型筛选
- 简单关系图可视化（节点+边）
- 导出 Cytoscape/Graphviz

### 3.10 Notifications 页面

- 通知渠道列表（类型、状态、配置）
- 渠道测试
- 渠道启用/禁用

### 3.11 Settings 页面

- i18n 语言切换
- 缓存配置（Redis URL）
- 系统信息（版本、运行时间）

## 4. 技术实现

### 4.1 前端

- **纯 HTML/CSS/JS**：无框架依赖，保持 dashboard/index.html 风格
- **Fetch API**：调用 collab_api.py REST 端点
- **响应式设计**：支持 1024px+ 屏幕
- **实时刷新**：每 30s 自动刷新统计数据

### 4.2 后端 API 复用

直接复用现有端点：

| 端点 | 用途 |
|------|------|
| GET /agents | Agent 列表 |
| GET /tasks | Task 列表 |
| GET /workspaces | Workspace 列表 |
| GET /quotas | 配额信息 |
| GET /audit/logs | 审计日志 |
| GET /experiments | 实验列表 |
| GET /experiments/{id}/results | 实验结果 |
| GET /kg/nodes | KG 节点 |
| GET /kg/stats | KG 统计 |
| GET /notifications/channels | 通知渠道 |
| GET /cache/stats | 缓存状态 |
| GET /i18n/locales | 语言列表 |
