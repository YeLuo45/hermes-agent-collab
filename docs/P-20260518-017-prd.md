# P-20260518-017 PRD: 配置热更新（Direction R）

## 1. 目标

hermes-agent-collab 支持运行时配置热更新，无需重启服务即可使配置变更生效。提供基于文件轮询（watchdog）+ 信号触发（SIGUSR1）+ REST API（POST /admin/config/reload）三种触发机制，配置变更自动应用到各组件（Rate Limiter / Tracing / Redis / Channel Adapter 等）。

## 2. 背景

当前 `CollabConfig` 在服务启动时从环境变量加载一次，后续无法动态修改。生产环境需要调整限流阈值、日志级别、Redis 连接参数时必须重启服务，影响可用性。

## 3. 设计方案

### 3.1 配置加载架构

```
CollabConfig ( dataclass )
    │
    ├── _load_env()          ← 启动时一次性加载
    ├── _load_file(path)     ← 热更新时从 YAML/JSON 文件加载
    └── reload()             ← 合并增量更新到运行中实例
```

### 3.2 配置源优先级

`REST API (POST /admin/config/reload)` > `SIGHUP 信号` > `YAML 配置文件轮询` > `环境变量`

### 3.3 三种触发机制

#### A. 文件轮询（watchdog）

```python
# collaboration/config_watcher.py
class ConfigWatcher:
    """监控配置文件变化，自动触发 reload"""

    def __init__(self, config_path: str, poll_interval: float = 5.0):
        self._config_path = config_path
        self._poll_interval = poll_interval
        self._last_mtime = os.path.getmtime(config_path)
        self._scheduler: PriorityScheduler  # 已有的调度器
        self._running = False

    async def start(self):
        """启动轮询任务（低优先级，CRON_INTERVAL = LOW）"""
        ...

    def on_config_changed(self, event: ConfigChangedEvent):
        """配置变化时发送内部事件"""
        message_bus.publish(ConfigChangedEvent(path=self._config_path))
```

#### B. 信号触发（SIGUSR1）

```python
# collaboration/config_reloader.py
import signal

class ConfigReloader:
    """响应 SIGUSR1 信号，触发配置重载"""

    def __init__(self, config: CollabConfig, message_bus: AsyncMessageBus):
        self._config = config
        self._bus = message_bus

    def start(self):
        loop = asyncio.get_running_loop()
        loop.add_signal_handler(
            signal.SIGUSR1,
            lambda: asyncio.create_task(self._do_reload())
        )

    async def _do_reload(self):
        await self._bus.publish(ConfigReloadRequest(requester="SIGUSR1"))
```

### 3.4 配置变更事件总线

```python
# collaboration/events.py 新增
@dataclass
class ConfigChangedEvent(HookEvent):
    path: str
    updated_keys: list[str]
    reload_id: str
    timestamp: str

@dataclass
class ConfigReloadRequest(HookEvent):
    requester: str  # "SIGUSR1" | "file_watcher" | "REST_API"
```

### 3.5 组件级热更新回调

各组件注册回调，配置变更时自动刷新：

```python
# Rate Limiter 热更新
rate_limiter.update_limits(
    per_key=new_config.RATE_LIMIT_PER_KEY,
    burst=new_config.RATE_LIMIT_BURST,
    window=new_config.RATE_LIMIT_WINDOW
)

# Tracing 热更新（采样率）
if otel_tracer and new_config.TRACING_ENABLED:
    otel_tracer.update_sampler(new_config.TRACING_SAMPLE_RATE)

# Channel Adapter 热更新（重连）
if new_config.REDIS_HOST != old_config.REDIS_HOST:
    await channel_adapter.reconnect()
```

### 3.6 配置差异检测

```python
def compute_diff(old: CollabConfig, new: CollabConfig) -> dict[str, tuple[Any, Any]]:
    """返回前后配置值有变化的 key 列表"""
    diff = {}
    for field in fields(CollabConfig):
        old_val = getattr(old, field.name)
        new_val = getattr(new, field.name)
        if old_val != new_val:
            diff[field.name] = (old_val, new_val)
    return diff
```

## 5. 环境变量

| 变量 | 说明 |
|------|------|
| `CONFIG_WATCH_ENABLED` | 启用文件轮询（default: false） |
| `CONFIG_PATH` | 配置文件路径（default: /etc/hermes/collab.yaml） |
| `CONFIG_POLL_INTERVAL` | 轮询间隔秒数（default: 5.0） |
| `CONFIG_SIGNAL_ENABLED` | 启用 SIGUSR1 信号监听（default: true） |
| `CONFIG_API_ENABLED` | 启用 REST API 端点（default: true） |
| `CONFIG_ADMIN_KEY_REQUIRED` | API 端点需要 admin key（default: true） |

## 6. REST API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/admin/config` | 返回当前配置（脱敏） |
| POST | `/admin/config/reload` | 触发配置热更新 |
| GET | `/admin/config/diff` | 返回上次 reload 的差异 |
