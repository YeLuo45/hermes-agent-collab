# Direction AM: 缓存层增强（Redis 集成）

## 1. 目标

为 hermes-agent-collab 提供 Redis 缓存层，提升高频数据的访问性能，支持分布式 Session 共享、热点数据缓存、限流计数等场景。

## 2. 背景

当前系统（Direction AL）支持 i18n，但所有数据存储在内存/JSON 文件中。协作场景中需要：
- 高频访问的 Agent 状态、Task 状态缓存
- 跨实例 Session 共享
- 限流计数器（Redis INCR）
- 分布式锁（Redlock 模式）
- 热点数据（Template、Config）缓存

## 3. 功能范围

#### 3.1.2 CacheLayer

```python
class CacheLayer:
    """High-level caching facade over RedisCache."""
    
    def __init__(self, cache: RedisCache):
        self._cache = cache
    
    # Agent caching
    def get_agent(self, agent_id: str) -> dict | None:
        """Get cached agent state."""
    
    def set_agent(self, agent_id: str, data: dict, ttl: int = 300):
        """Cache agent state (5 min default)."""
    
    def invalidate_agent(self, agent_id: str):
        """Remove agent from cache."""
    
    # Task caching
    def get_task(self, task_id: str) -> dict | None:
        """Get cached task state."""
    
    def set_task(self, task_id: str, data: dict, ttl: int = 60):
        """Cache task state (1 min default)."""
    
    def invalidate_task(self, task_id: str):
        """Remove task from cache."""
    
    # Config caching
    def get_config(self, workspace_id: str) -> dict | None:
        """Get cached workspace config."""
    
    def set_config(self, workspace_id: str, data: dict, ttl: int = 3600):
        """Cache workspace config (1 hour default)."""
    
    # Rate limiting (sliding window)
    def rate_limit(self, key: str, limit: int, window: int) -> tuple[bool, int]:
        """
        Sliding window rate limiter.
        Returns (allowed, remaining).
        """
    
    # Distributed locking
    def acquire_lock(self, resource: str, timeout: int = 10) -> str | None:
        """
        Acquire distributed lock.
        Returns lock token if acquired.
        """
    
    def release_lock(self, resource: str, token: str) -> bool:
        """Release distributed lock."""
    
    def extend_lock(self, resource: str, token: str, ttl: int) -> bool:
        """Extend lock TTL."""
```

### 3.2 关键设计

- **线程安全**：所有操作加锁保护
- **连接池**：支持 connection pool
- **降级策略**：Redis 不可用时回退到内存缓存（DictCache）
- **Key 前缀**：所有 key 带前缀避免冲突（如 `hermes:agent:{id}`）
- **TTL 默认值**：Agent 5min, Task 1min, Config 1hour
- **Sliding Window**：限流使用滑动窗口算法
- **分布式锁**：简单 UUID token 模式（生产环境建议 Redlock）

### 3.3 API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/cache/stats` | 缓存统计 |
| GET | `/cache/keys` | 列出 key（支持前缀过滤） |
| GET | `/cache/get/{key}` | 获取值 |
| POST | `/cache/set` | 设置值 |
| DELETE | `/cache/del/{key}` | 删除 key |
| POST | `/cache/clear` | 清空所有缓存 |
| POST | `/cache/lock/{resource}` | 获取分布式锁 |
| DELETE | `/cache/lock/{resource}` | 释放锁 |
| POST | `/cache/ratelimit` | 限流检查 |
