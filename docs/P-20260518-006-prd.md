## 1. Overview

**Project**: hermes-agent-collab

## 2. Motivation

A/B/C/D 方向已构建了底层架构：
- A: 异步 MessageBus + Channel Adapter
- B: SQLite WAL 持久化
- C: TaskRouter 复杂度路由
- D: Hook/Plugin 生命周期扩展

**Direction E** 需要在这些之上构建正式的多Agent协作协议，让 Agent 之间能以结构化方式通信、委托任务、匹配能力、同步状态。

## 3. Architecture

### 3.1 MultiAgentProtocol

核心通信协议类（`collaboration/protocol.py`）：

```
AgentMessage (IM)
├── msg_id: UUID
├── sender_id: Agent ID
├── receiver_id: Agent ID (None = broadcast)
├── session_id: UUID (for correlated request/response)
├── msg_type: MessageType
├── payload: dict
├── correlation_id: UUID (for reply tracking)
├── timestamp: ISO8601
├── ttl_seconds: int (default 300)
└── status: MessageStatus (pending/delivered/acked/failed)

MessageType (Enum):
- REQUEST_TASK   (coordinator → worker)
- RESPONSE_RESULT (worker → coordinator)
- CAPABILITY_QUERY (who can do X?)
- CAPABILITY_ANNOUNCE (I can do X)
- STATE_SYNC     (periodic heartbeat/state broadcast)
- DELEGATION     (I assign this to you)
- ACKNOWLEDGMENT (task received)
- HEARTBEAT      (I'm alive)
- ERROR_REPORT   (something went wrong)
```

### 3.2 AgentSession

管理一组 Agent 之间的对话上下文：

```
AgentSession
├── session_id: UUID
├── participants: set[agent_id]
├── context: dict (shared context)
├── messages: list[AgentMessage]
├── created_at: ISO8601
├── updated_at: ISO8601
└── status: SessionStatus
```

### 3.3 TaskDistribution

任务分发策略：

```
TaskDistribution
├── task_id: str
├── delegation_policy: DelegationPolicy
│   ├── type: "broadcast" | "capability_match" | "指定"
│   ├── timeout_seconds: int
│   ├── retry_count: int
│   └── min_confidence: float
├── candidates: list[agent_id]
├── assigned_agents: list[agent_id]
└── distribution_result: DistributionResult
```

### 3.4 CapabilityMatchResult

能力匹配结果：

```
CapabilityMatchResult
├── query: str
├── matched_agents: list[tuple[agent_id, confidence_score]]
├── best_candidate: agent_id | None
└── match_method: "exact" | "keyword" | "embedding"
```

## 4. API Design

### 4.1 MultiAgentProtocol

```python
class MultiAgentProtocol:
    def __init__(self, workspace_id: str)
    
    # ─── Messaging ────────────────────────────────────────────
    def send_message(
        self,
        sender_id: str,
        receiver_id: str | None,  # None = broadcast
        msg_type: MessageType,
        payload: dict,
        session_id: str | None = None,
        correlation_id: str | None = None,
        ttl_seconds: int = 300,
    ) -> AgentMessage
    
    def acknowledge_message(self, msg_id: str, agent_id: str) -> bool
    
    def get_pending_messages(self, agent_id: str) -> list[AgentMessage]
    
    # ─── Sessions ─────────────────────────────────────────────
    def create_session(self, participants: list[str], context: dict = None) -> AgentSession
    
    def get_session(self, session_id: str) -> AgentSession | None
    
    def end_session(self, session_id: str) -> bool
    
    # ─── Task Distribution ────────────────────────────────────
    def distribute_task(
        self,
        task_id: str,
        description: str,
        policy: DelegationPolicy,
        required_capabilities: list[str] | None = None,
    ) -> TaskDistribution
    
    def get_distribution_status(self, distribution_id: str) -> TaskDistribution
    
    # ─── Capability Matching ──────────────────────────────────
    def match_capabilities(
        self,
        query: str,
        required_capabilities: list[str],
        min_confidence: float = 0.5,
    ) -> CapabilityMatchResult
    
    # ─── Timeout Handling ─────────────────────────────────────
    def check_timeouts(self) -> list[AgentMessage]  # returns expired messages
```

### 4.2 Built-in Delegation Policies

## 5. Storage Schema

SQLite backend (`storage.py` already has WAL mode):

```sql
CREATE TABLE IF NOT EXISTS agent_messages (
    msg_id TEXT PRIMARY KEY,
    sender_id TEXT NOT NULL,
    receiver_id TEXT,
    session_id TEXT,
    msg_type TEXT NOT NULL,
    payload TEXT,  -- JSON
    correlation_id TEXT,
    timestamp REAL NOT NULL,
    ttl_seconds INTEGER DEFAULT 300,
    status TEXT DEFAULT 'pending'
);

CREATE TABLE IF NOT EXISTS agent_sessions (
    session_id TEXT PRIMARY KEY,
    participants TEXT NOT NULL,  -- JSON array
    context TEXT,                 -- JSON
    messages TEXT,               -- JSON array (recent)
    created_at REAL NOT NULL,
    updated_at REAL NOT NULL,
    status TEXT DEFAULT 'active'
);

CREATE TABLE IF NOT EXISTS task_distributions (
    distribution_id TEXT PRIMARY KEY,
    task_id TEXT NOT NULL,
    delegation_policy TEXT NOT NULL,  -- JSON
    candidates TEXT,                   -- JSON array
    assigned_agents TEXT,              -- JSON array
    distribution_result TEXT,          -- JSON
    created_at REAL NOT NULL,
    status TEXT DEFAULT 'pending'
);
```
