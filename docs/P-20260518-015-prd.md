# PRD: Direction N — 任务优先级调度器 + 抢占式执行

## 1. Problem Statement

当前任务调度为 FIFO（先进先出），存在以下问题：
- **紧急任务无法插队**：高优先级任务必须等待队列中所有低优先级任务完成
- **资源分配不公平**：长时间运行的任务占用所有算力，短任务被饿死
- **无差异化 SLA**：所有任务使用相同队列，无法区分实时任务和后台批处理
- **缺乏抢占机制**：正在执行的任务无法被更高优先级任务中断

## 2. Architecture

### 2.1 优先级分层

| 优先级 | 名称 | 用途 | 抢占规则 |
|--------|------|------|---------|
| P0 | CRITICAL | 系统级关键任务（健康检查、熔断） | 可抢占 P1-P3 |
| P1 | HIGH | 用户发起的高价值任务 | 可抢占 P2-P3 |
| P2 | NORMAL | 常规任务 | 可抢占 P3 |
| P3 | LOW | 后台批处理、数据同步 | 不可抢占 |

### 2.2 调度器架构

```
PriorityScheduler (单例)
    ├── PriorityQueue[4] (每个优先级一个队列)
    ├── WorkerPool (N 个 Worker)
    ├── TaskRunner (执行单元)
    └── PreemptionManager (抢占决策)
```

### 2.3 抢占机制

```
P1 任务到达
    ↓
检查是否有 P2/P3 任务正在执行
    ↓
是 → 暂停当前任务，保存状态
    ↓
执行 P1 任务
    ↓
完成后恢复被抢占的任务
```

### 2.4 任务状态机

```
PENDING → RUNNING → COMPLETED
           ↓              ↑
      (可被抢占)      (恢复后继续)
           ↓
       PREEMPTED → (等待重新调度)
           ↓
         FAILED
```

## 3. 接口设计

### 3.1 TaskPriority Enum

```python
class TaskPriority(int, Enum):
    CRITICAL = 0
    HIGH = 1
    NORMAL = 2
    LOW = 3
```

### 3.2 PriorityTask

```python
@dataclass
class PriorityTask:
    task_id: str
    priority: TaskPriority
    payload: Any
    created_at: datetime
    deadline: datetime | None = None  # 截止时间
    max_retries: int = 3
    preemption_allowed: bool = True
    state: TaskState = TaskState.PENDING
    checkpoint: dict | None = None  # 抢占恢复点
```

### 3.3 Scheduler API

```python
class PriorityScheduler:
    async def submit(task: PriorityTask) -> str:
        """提交任务，返回 task_id"""

    async def cancel(task_id: str) -> bool:
        """取消任务（仅 PENDING 状态可取消）"""

    async def get_status(task_id: str) -> TaskStatus:
        """获取任务状态"""

    async def list_tasks(priority: TaskPriority | None = None) -> list[PriorityTask]:
        """列出任务"""

    # 配置
    max_workers: int = 4
    preemption_enabled: bool = True
    starvation_threshold: int = 300  # 秒，低优先级任务最长等待时间
```

## 4. 与现有 TaskManager 集成

```python
# TaskManager 新增方法
TaskManager.submit_task(task, priority=TaskPriority.NORMAL)
TaskManager.preempt_running_task(task_id: str)  # 强制抢占
TaskManager.set_task_deadline(task_id: str, deadline: datetime)
```
