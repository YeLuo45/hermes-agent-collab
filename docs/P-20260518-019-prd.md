# P-20260518-019 PRD: Webhook 事件订阅系统（Direction T）

## 1. 目标

hermes-agent-collab 支持外部 Webhook 订阅，当工作流事件（任务完成、Agent 状态变更、消息到达）发生时，通过 HTTP POST 回调通知外部系统。提供事件过滤、签名验证（HMAC-SHA256）、重试机制（指数退避）和端点管理 UI。

## 2. 背景

外部系统（如 CI/CD 流水线、数据分析管道、其他 Agent 系统）需要实时感知 hermes-agent-collab 内部事件。当前的 HookPlugin 机制仅支持内部组件回调，不支持向外部 HTTP 端点推送事件。

## 3. 设计方案

### 3.1 Webhook 订阅模型

```python
# collaboration/models.py 新增

@dataclass
class WebhookSubscription:
    id: str
    workspace_id: str | None          # None = 全局订阅
    url: str                          # 回调目标 URL
    events: list[str]                 # 订阅的事件类型
    secret: str                       # HMAC-SHA256 签名密钥
    enabled: bool = True
    created_at: str
    retry_count: int = 3              # 失败重试次数
    retry_delay: float = 1.0          # 初始重试延迟（秒）
    active: bool = True               # 是否激活（连续失败后自动禁用）
    last_triggered_at: str | None = None
    last_success_at: str | None = None
    last_failure_at: str | None = None
    last_error: str | None = None
```

### 3.2 事件类型

| 事件类型 | 说明 |
|----------|------|
| `task.created` | 新任务创建 |
| `task.started` | 任务开始执行 |
| `task.completed` | 任务完成 |
| `task.failed` | 任务失败 |
| `task.preempted` | 任务被抢占 |
| `agent.registered` | Agent 注册 |
| `agent.status_changed` | Agent 状态变更 |
| `message.received` | 收到新消息 |
| `workspace.created` | 工作空间创建 |
| `hook.triggered` | 任意 Hook 触发（通配） |

### 3.3 签名验证

每个 Webhook 请求携带：

```
X-Webhook-Signature: sha256=<hex_digest>
X-Webhook-Timestamp: <unix_timestamp>
X-Webhook-Event: <event_type>
X-Webhook-Delivery-ID: <uuid>
```

签名计算：`HMAC-SHA256(secret, timestamp + "." + payload)`

接收方验证：
1. 检查 `X-Webhook-Timestamp` 与服务器时间差 < 5 分钟（防止重放攻击）
2. 计算 `HMAC-SHA256(secret, timestamp + "." + payload)`，比对签名

        ...

    async def retry_with_backoff(self) -> DeliveryResult:
        """指数退避重试：delay * 2^(attempt-1)，最大 60s"""

### 3.5 事件过滤

- `events` 字段支持精确匹配（`task.completed`）或前缀通配（`task.*`）
- `workspace_id` 限定工作空间范围
- 订阅创建时可指定 `event_filter` JSONPath 表达式
