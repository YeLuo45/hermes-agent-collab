# Direction AI: A/B 测试框架（策略对比实验）

## 1. 目标

为 hermes-agent-collab 提供 A/B 测试框架，支持在生产环境中对不同策略（Agent 分配策略、任务路由策略等）进行对比实验，通过统计显著性分析确定最优方案。

## 2. 背景

当前系统（Direction AH）支持通知管道，但缺乏实验能力。协作场景中需要：
- 对比不同 Agent 分配策略的效果
- 评估不同任务路由策略的性能差异
- 灰度发布新功能，逐步切分流量
- 数据驱动的策略优化决策

## 3. 功能范围

### 3.1 A/B 测试架构

```
ExperimentManager
    ├── Experiment: name, variants, traffic_allocation, metrics
    ├── Variant: id, name, config, traffic_weight
    ├── Metric: name, type, higher_is_better
    └── Result: variant_id, sample_size, mean, stddev, p_value, significance
```

### 3.2 核心组件

#### 3.2.1 ExperimentManager

```python
class ExperimentManager:
    """Manages A/B experiments lifecycle."""
    
    def create_experiment(self, name: str, variants: list[Variant], 
                         metrics: list[str], traffic_allocation: float = 1.0) -> str:
        """Create a new experiment. Returns experiment ID."""
    
    def get_variant(self, experiment_id: str, entity_id: str) -> Variant:
        """Get variant for an entity (consistent hashing)."""
    
    def record_metric(self, experiment_id: str, variant_id: str, 
                     entity_id: str, value: float) -> None:
        """Record a metric observation."""
    
    def get_results(self, experiment_id: str) -> ExperimentResults:
        """Compute statistical significance and return results."""
    
    def list_experiments(self) -> list[ExperimentSummary]:
        """List all experiments with their status."""
```

@dataclass

#### 3.2.3 统计方法

- **Z-test**：两样本比例 Z 检验（binary metrics）
- **Welch's t-test**：两样本均值 t 检验（continuous metrics）
- **Bonferroni 校正**：多重比较校正
- **最小样本量**：基于功效分析（power = 0.8, alpha = 0.05）
- **可信度**：95% 置信区间

### 3.3 关键设计

- **一致性哈希**：同一 entity_id 始终路由到同一 variant（幂等保证）
- **流量分配**：支持不均匀分配（如 10% B variant，90% control）
- **Metric 类型**：`counter`（转化率）、`gauge`（均值对比）、`latency`
- **自动停止**：达到最小样本量后自动计算显著性
- **分层实验**：支持多个独立实验共享同一流量池

### 3.4 API 端点
