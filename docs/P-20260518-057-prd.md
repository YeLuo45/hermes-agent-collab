# Direction AJ: Playground / REPL 沙盒环境

## 1. 目标

为 hermes-agent-collab 提供 Playground / REPL 沙盒环境，支持在线编写、预览、调试协作工作流，降低新用户上手门槛，同时作为内部开发者的调试工具。

## 2. 背景

当前系统（Direction AI）支持 A/B 测试框架，但缺乏交互式 Playground。协作场景中需要：
- 零门槛体验工作流执行效果
- 在线调试复杂任务图
- 即时预览 Agent 协作行为
- 分享和导出 Playground 快照

## 3. 功能范围

### 3.1 Playground 架构

```
PlaygroundManager
    ├── Sandbox: isolated execution context
    ├── REPLSession: interactive Python-like REPL
    ├── WorkflowPreview: render workflow as DAG graph
    └── Snapshot: saved playground state
```

### 3.2 核心组件

#### 3.2.1 Sandbox

```python
@dataclass
class Sandbox:
    """Isolated execution context for playground."""
    session_id: str
    workspace_id: str
    created_at: str
    ttl_seconds: int = 3600  # 1 hour default
    max_steps: int = 1000
    timeout_seconds: int = 30
```

#### 3.2.2 REPLSession

```python
class REPLSession:
    """Interactive REPL session for testing agent logic."""
    
    def execute(self, code: str) -> REPLResult:
        """Execute Python-like code in sandbox."""
    
    def evaluate(self, expr: str) -> str:
        """Evaluate expression and return result."""
    
    def get_history(self) -> list[REPLResult]:
        """Get all executed commands and results."""
```

#### 3.2.3 WorkflowPreview

```python
class WorkflowPreview:
    """Render and preview workflow definitions as DAG."""
    
    def from_template(self, template_id: str, params: dict) -> DAG:
        """Instantiate template with params and return DAG."""
    
    def to_mermaid(self, dag: DAG) -> str:
        """Convert DAG to Mermaid markdown."""
    
    def validate(self, dag: DAG) -> list[str]:
        """Validate DAG and return errors."""
```

### 3.3 关键设计

- **安全沙盒**：代码执行使用 `exec()` 限制，禁用危险内置函数
- **REPL 超时**：单次执行 timeout 30s，防止无限循环
- **TTL 自动清理**：Sandbox 默认 1 小时过期
- **Workflow Preview**：将 template 实例化为 Mermaid DAG 预览
- **Snapshot 分享**：Playground 状态可序列化分享

### 3.4 API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/playground/sandbox` | 创建沙盒 |
| GET | `/playground/sandbox/{id}` | 获取沙盒状态 |
| DELETE | `/playground/sandbox/{id}` | 删除沙盒 |
| POST | `/playground/sandbox/{id}/execute` | 执行代码 |
| GET | `/playground/sandbox/{id}/history` | 获取 REPL 历史 |
| POST | `/playground/preview` | 预览 workflow DAG |
| POST | `/playground/snapshot` | 保存快照 |
| GET | `/playground/snapshot/{id}` | 加载快照 |
