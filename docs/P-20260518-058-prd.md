# Direction AK: 知识图谱增强（实体关系可视化）

## 1. 目标

为 hermes-agent-collab 提供知识图谱能力，支持 Agent、Task、Template 等实体之间关系的建模与可视化，实现协作生态的全链路知识沉淀和关系推理。

## 2. 背景

当前系统（Direction AJ）支持 Playground 沙盒，但缺乏知识图谱能力。协作场景中需要：
- 将 Agent、Task、Workspace、Template 等实体建模为图谱节点
- 支持实体之间多维度关系（依赖、引用、协作、继承）
- 提供 Cypher-like 查询语言
- 可视化展示实体关系网络

## 3. 功能范围

### 3.1 图谱数据模型

```
Node: {
    id: str,           # 唯一标识
    labels: list[str], # 标签集（Agent/Task/Template等）
    properties: dict,   # 属性键值对
    created_at: str,
}

Relationship: {
    id: str,
    type: str,          # 关系类型（DEPENDS_ON/BELONGS_TO/COLLABORATES等）
    source_id: str,    # 起始节点
    target_id: str,    # 目标节点
    properties: dict,
    created_at: str,
}
```

### 3.2 核心组件

#### 3.2.1 KGNode / KGRelationship

```python
@dataclass
class KGNode:
    id: str
    labels: list[str]
    properties: dict
    created_at: str

@dataclass
class KGRelationship:
    id: str
    type: str
    source_id: str
    target_id: str
    properties: dict
    created_at: str
```

#### 3.2.2 KnowledgeGraph

```python
class KnowledgeGraph:
    """In-memory knowledge graph with Cypher-like query support."""
    
    def add_node(self, node: KGNode) -> bool:
        """Add a node to the graph."""
    
    def add_relationship(self, rel: KGRelationship) -> bool:
        """Add a relationship between two nodes."""
    
    def get_node(self, node_id: str) -> KGNode | None:
        """Get node by ID."""
    
    def get_neighbors(self, node_id: str, rel_type: str | None = None) -> list[KGNode]:
        """Get neighboring nodes."""
    
    def query(self, cypher: str) -> list[dict]:
        """Execute Cypher-like query."""
    
    def traverse(self, start_id: str, depth: int = 3) -> list[KGNode]:
        """BFS traversal from a node."""
    
    def to_cytoscape(self) -> dict:
        """Export graph as Cytoscape.js JSON."""
    
    def to_graphviz(self) -> str:
        """Export graph as Graphviz DOT."""
```

### 3.3 关键设计

- **内存图存储**：使用 dict + set 实现高性能图遍历
- **Cypher-like 查询**：支持 `MATCH (n:Label) WHERE n.prop = 'value' RETURN n`
- **关系类型**：DEPENDS_ON, BELONGS_TO, COLLABORATES_WITH, USES, DEFINED_BY, INSTANCE_OF
- **可视化导出**：支持 Cytoscape.js JSON + Graphviz DOT 格式
- **BFS 遍历**：支持按深度限制的图遍历

### 3.4 API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/kg/nodes` | 创建节点 |

| POST | `/kg/relationships` | 创建关系 |
| DELETE | `/kg/relationships/{id}` | 删除关系 |
| GET | `/kg/nodes/{id}/neighbors` | 邻居节点 |

| POST | `/kg/traverse` | 图遍历 |
| GET | `/kg/export/cytoscape` | Cytoscape.js 导出 |
| GET | `/kg/export/graphviz` | Graphviz DOT 导出 |
| GET | `/kg/stats` | 图谱统计 |
