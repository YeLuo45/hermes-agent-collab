# Direction AG: 分布式追踪增强（Jaeger 集成）

## 1. 目标

为 hermes-agent-collab 集成 OpenTelemetry + Jaeger 分布式追踪，实现请求级别的全链路可观测性，支持追踪任务执行、Agent 协作、跨服务调用的可视化。

## 2. 背景

当前系统（Direction AF）支持实时协作编辑，但缺乏分布式追踪能力。协作场景中需要：
- 全链路追踪：从 HTTP 请求 → Agent 协作 → 任务执行 → 存储的全流程可视化
- 性能剖析：识别跨 Agent 协作的瓶颈
- 错误追踪：快速定位分布式环境中的错误传播路径

## 3. 功能范围

### 3.1 追踪架构

```
HTTP Request / Agent Task
    ↓
OpenTelemetry SDK (traceloop)
    ↓
OTLP Exporter → Jaeger Agent (UDP 6831)
    ↓
Jaeger Collector → Jaeger UI (前端展示)
```

### 3.2 核心组件

#### 3.2.1 TracingManager

```python
class TracingManager:
    """Manages OpenTelemetry tracers for hermes-agent-collab."""
    
    def init(self, service_name: str, endpoint: str = "http://localhost:6831"):
        """Initialize tracer provider with Jaeger OTLP exporter."""
    
    def start_span(self, name: str, attrs: dict | None = None) -> SpanContext:
        """Start a new span."""
    
    def end_span(self, span: SpanContext, status: str = "OK"):
        """End a span."""
    
    def record_exception(self, span: SpanContext, exc: Exception):
        """Record an exception on a span."""
    
    def add_span_attrs(self, span: SpanContext, attrs: dict):
        """Add attributes to an existing span."""
```

#### 3.2.2 追踪点

| 操作 | Span 名称 | 属性 |
|------|-----------|------|
| HTTP 请求 | `http.request` | method, path, status_code, workspace_id |
| Agent 注册 | `agent.register` | agent_id, agent_type, workspace_id |
| Agent 协作消息 | `agent.collaborate` | task_id, from_agent, to_agent, msg_type |
| 任务执行 | `task.execute` | task_id, priority, strategy_id |
| 策略编排 | `strategy.compose` | strategy_id, step_count |
| 工作流执行 | `workflow.run` | workflow_id, template_id |
| 实时协作操作 | `collab.operation` | session_id, resource_type, op_type |
| 数据库操作 | `db.operation` | operation, table, row_count |
| 配置热更新 | `config.reload` | changed_keys, requester |

#### 3.2.3 Jaeger UI 端点

```
http://localhost:16686  (默认 Jaeger UI)
```

### 3.3 关键设计

- 采样策略：Head-based sampling（100% 在开发环境，生产环境 10%）
- Span Context 传播：通过 HTTP header（traceparent）实现跨服务传播
- 日志集成：span events 自动关联应用日志
- 异步任务：使用 context manager 自动管理 span 生命周期
- 零侵入：通过装饰器 `@with_trace("operation_name")` 包装关键函数
