# P-20260518-007 PRD: REST API + SSE Real-time Events Layer (Direction F)

## 1. Overview

**Project**: hermes-agent-collab
**Proposal ID**: P-20260518-007
**Direction**: F
**Inspiration**: chatdev-design (API-first), thunderbolt-design (event streaming)

Build production-grade REST API exposing all internal capabilities, with SSE real-time event streaming. Key additions over existing partial SSE:
- Full MultiAgentProtocol API endpoints (send_message, create_session, distribute_task)
- Orchestration lifecycle endpoints (create/update/stream)
- Hook/plugin management endpoints
- Workspace-scoped SSE streams with event filtering
- SSE reconnect support with resume token

### 2.2 Event Streaming

- SSE endpoint at `/api/collab/v1/events`
- Workspace-scoped: `/api/collab/v1/workspaces/{ws_id}/events`
- Event type filter: `?types=task.created,agent.registered`
- Resume token: `?cursor=<last_event_id>` for reconnect support
- Heartbeat: every 30s to keep connection alive

### 5.2 Key Implementation Details

**SSE Reconnect Token**:
- Each event has a monotonically increasing `seq` (integer)
- Client sends `?cursor=<last_seq>` to resume from last event
- Server maintains 10,000 event ring buffer per workspace
- Events older than cursor are skipped

**SSE Format**:
```
event: task.created
id: 12345
data: {"task_id": "t1", "workspace_id": "ws1", "timestamp": "..."}

event: heartbeat
id: 12346
data: {"ts": "..."}
```

**Workspace Isolation**:
- Each workspace has independent SSE stream
- Clients must specify `workspace_id` in path or query
- Events are filtered by workspace before sending
