## 1. Overview

**Project**: hermes-agent-collab

**Stage**: prd_pending_confirmation

## 2. Problem Statement

Current `SkillSystem` is a passive skill registry (create/read/update/delete/list). There is no way to:
- Attach behavior (hooks) to events (task created, phase transitioned, agent registered)
- Extend the system with custom plugins without modifying core code
- Chain multiple handlers for the same lifecycle event
- Enable/disable plugins at runtime
- Scope hooks to specific workspaces or globally

## 3. Proposed Solution

### 3.1 Hook Lifecycle Events

Define a set of lifecycle events that plugins can subscribe to:

```python
class HookEvent(str, Enum):
    # Agent lifecycle
    AGENT_REGISTERED = "agent.registered"
    AGENT_DEREGISTERED = "agent.deregistered"
    AGENT_STATUS_CHANGED = "agent.status_changed"

    # Task lifecycle
    TASK_CREATED = "task.created"
    TASK_UPDATED = "task.updated"
    TASK_COMPLETED = "task.completed"
    TASK_FAILED = "task.failed"

    # Orchestration lifecycle
    ORCHESTRATION_CREATED = "orchestration.created"
    ORCHESTRATION_PHASE_CHANGED = "orchestration.phase_changed"
    ORCHESTRATION_COMPLETED = "orchestration.completed"

    # Skill lifecycle
    SKILL_REGISTERED = "skill.registered"
    SKILL_ENABLED = "skill.enabled"
    SKILL_DISABLED = "skill.disabled"

    # System
    WORKSPACE_INITIALIZED = "workspace.initialized"
    SYSTEM_READY = "system.ready"
```

### 3.2 Hook Handler Signature

```python
from typing import Any, Callable, Protocol

HookHandler = Callable[[dict[str, Any]], Any | None]
# Event dict contains event-specific payload (e.g., {"agent_id": "...", "status": "..."})
```

### 3.3 Plugin Model

Extend `Skill` with plugin capability:

```python
@dataclass
class Plugin:
    plugin_id: str
    name: str
    description: str
    version: str
    enabled: bool
    hook_handlers: dict[HookEvent, list[str]]  # event -> [handler_id list]
    config: dict[str, Any]
    metadata: dict[str, Any]
    created_at: str
    updated_at: str
```

### 3.4 PluginRegistry Class

```python
class PluginRegistry:
    """Central registry for hooks and plugins."""

    def __init__(self, workspace_id: str = None):
        self._handlers: dict[HookEvent, list[tuple[str, HookHandler]]] = defaultdict(list)
        self._plugins: dict[str, Plugin] = {}
        self._lock = threading.Lock()

    def register_plugin(self, plugin: Plugin) -> None:
        """Register a plugin and its handlers."""

    def unregister_plugin(self, plugin_id: str) -> list[HookEvent]:
        """Remove plugin and all its handlers. Returns removed event types."""

    def subscribe(self, event: HookEvent, handler: HookHandler, plugin_id: str = "system") -> str:
        """Subscribe a handler to an event. Returns handler_id."""

    def unsubscribe(self, event: HookEvent, handler_id: str) -> bool:
        """Remove a specific handler."""

    def emit(self, event: HookEvent, payload: dict[str, Any]) -> list[Any]:
        """Fire all handlers for event. Returns list of non-None results."""

    def list_plugins(self) -> list[Plugin]:
        """List all registered plugins."""

    def get_plugin(self, plugin_id: str) -> Plugin | None:
        """Get plugin by ID."""

    def enable_plugin(self, plugin_id: str) -> bool:
        """Enable a plugin and its handlers."""

    def disable_plugin(self, plugin_id: str) -> bool:
        """Disable a plugin (handlers stay registered but skip execution)."""
```

### 3.5 Hook Points in Existing Code

Insert hook emissions at key points:

| Location | Event | Payload |
|----------|-------|---------|
| `agent_registry.py` register | `AGENT_REGISTERED` | `{agent_id, name, role, capabilities}` |
| `task_manager.py` create_task | `TASK_CREATED` | `{task_id, title, complexity}` |
| `task_manager.py` transition_phase | `TASK_PHASE_CHANGED` | `{task_id, from_phase, to_phase}` |
| `orchestration_manager.py` create_orchestration | `ORCHESTRATION_CREATED` | `{orchestration_id, coordinator_id}` |
| `orchestration_manager.py` update_phase | `ORCHESTRATION_PHASE_CHANGED` | `{orchestration_id, from_phase, to_phase}` |
| `skill_system.py` create_skill | `SKILL_REGISTERED` | `{skill_id, name, category}` |
| `skill_system.py` enable_skill | `SKILL_ENABLED` | `{skill_id}` |
| `skill_system.py` disable_skill | `SKILL_DISABLED` | `{skill_id}` |

### 3.6 Global vs Workspace Scoped Hooks

```python
# Global registry (no workspace_id)
_global_registry = PluginRegistry()

# Per-workspace registry
_workspace_registries: dict[str, PluginRegistry] = {}
_workspace_lock = threading.Lock()

def get_registry(workspace_id: str = None) -> PluginRegistry:
    """Get global or workspace-scoped registry."""
    if workspace_id is None:
        return _global_registry
    with _workspace_lock:
        if workspace_id not in _workspace_registries:
            _workspace_registries[workspace_id] = PluginRegistry(workspace_id)
        return _workspace_registries[workspace_id]
```

### 3.7 Example Plugin: TaskMetricsPlugin

```python
class TaskMetricsPlugin(Plugin):
    """Built-in plugin that tracks task completion metrics."""

    def __init__(self):
        self.plugin_id = "builtin:task_metrics"
        self.name = "Task Metrics"
        self.description = "Tracks task completion times and success rates"
        self.version = "1.0.0"
        self.enabled = True
        self.hook_handlers = {
            HookEvent.TASK_CREATED: ["_on_task_created"],
            HookEvent.TASK_COMPLETED: ["_on_task_completed"],
            HookEvent.TASK_FAILED: ["_on_task_failed"],
        }
        self._metrics = {"created": 0, "completed": 0, "failed": 0, "durations": []}

    def _on_task_created(self, payload):
        self._metrics["created"] += 1

    def _on_task_completed(self, payload):
        self._metrics["completed"] += 1
        # payload may contain duration

    def _on_task_failed(self, payload):
        self._metrics["failed"] += 1

    def get_metrics(self) -> dict:
        return dict(self._metrics)
```
