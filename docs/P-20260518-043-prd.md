# Direction Z: 敏感数据脱敏

## 1. 目标

为 hermes-agent-collab 提供敏感数据（API Key、Token、密钥）的安全存储能力，确保敏感信息不以明文形式写入磁盘或日志。

## 2. 背景

当前系统（Direction T）支持 Webhook 回调，API Key 存储在 JSON 文件中为明文。协作场景中，用户需要：
- API Key/Token 安全存储（不暴露原始值）
- 日志脱敏（禁止敏感字段写入日志）
- 敏感数据只在前端显示部分字符（脱敏展示）

## 3. 功能范围

### 3.1 核心功能

#### 3.1.1 加密存储

```python
class SecretStore:
    """AES-GCM 加密敏感数据，使用 Fernet (cryptography Fernet)."""
    
    def store(self, key: str, value: str) -> str:
        """存储加密后的密文，返回加密引用 ID"""
    
    def retrieve(self, ref_id: str) -> str:
        """根据引用 ID 解密并返回原始值"""
    
    def delete(self, ref_id: str) -> None:
        """删除加密引用"""
    
    def rotate(self, ref_id: str, new_value: str) -> str:
        """轮换密钥（重新加密）"""
```

#### 3.1.2 日志脱敏处理器

```python
class SecretRedactingFilter(logging.Filter):
    """日志处理器：自动脱敏已知敏感字段"""
    
    SENSITIVE_KEYS = [
        'api_key', 'token', 'secret', 'password', 'access_token',
        'refresh_token', 'authorization', 'x_hermes_signature',
        'webhook_secret', 'hmac_key',
    ]
    
    def filter(self, record):
        #递归脱敏 record.msg 和 record.args
```

#### 3.1.3 API 响应脱敏中间件

```python
class SecretRedactingMiddleware:
    """在序列化响应前脱敏所有 Pydantic 模型中的敏感字段"""
    
    SENSITIVE_FIELDS = {'api_key', 'token', 'secret', 'password'}
```

#### 3.1.4 安全配置

```python
# .env 示例
SECRET_ENCRYPTION_KEY=<base64 编码的 32 字节密钥>
SECRET_STORE_ENABLED=true
LOG_REDACT_ENABLED=true
RESPONSE_MASK_ENABLED=true
```

### 3.2 API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/secrets` | 加密存储敏感值（返回 ref_id） |
| GET | `/secrets/{ref_id}` | 解密获取原始值（需要认证） |
| DELETE | `/secrets/{ref_id}` | 删除加密引用 |
| POST | `/secrets/{ref_id}/rotate` | 轮换密钥 |

### 4.2 改造文件

### 4.3 密钥管理

- 使用 `cryptography.fernet.Fernet`（AES-128-CBC + HMAC）
- 密钥来自环境变量 `SECRET_ENCRYPTION_KEY`（base64 编码）
- 支持密钥轮换（重新生成 Fernet 实例）
