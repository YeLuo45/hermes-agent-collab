# Direction AC: 配置验证 Schema

## 1. 目标

为 hermes-agent-collab 提供 JSON Schema 配置验证能力，在配置热更新（Direction R）生效前进行前置校验，确保非法配置不会导致运行时崩溃。

## 2. 背景

当前系统（Direction R）支持配置热更新，但更新时直接 apply_changes，不做预校验。若配置格式错误（如缺少必填字段、类型错误），可能导致系统进入不可用状态。

## 3. 功能范围

### 3.1 JSON Schema 定义

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "required": ["version", "limits", "features"],
  "properties": {
    "version": { "type": "string", "pattern": "^\\d+\\.\\d+\\.\\d+$" },
    "limits": {
      "type": "object",
      "properties": {
        "max_agents": { "type": "integer", "minimum": 1, "maximum": 10000 },
        "max_tasks_per_agent": { "type": "integer", "minimum": 1 },
        "max_workspace_memory_mb": { "type": "integer", "minimum": 64 },
        "rate_limit_per_minute": { "type": "integer", "minimum": 1 }
      }
    },
    "features": {
      "type": "object",
      "properties": {
        "webhooks_enabled": { "type": "boolean" },
        "grpc_enabled": { "type": "boolean" },
        "telemetry_enabled": { "type": "boolean" },
        "multi_tenant": { "type": "boolean" }
      }
    },
    "quotas": {
      "type": "object",
      "additionalProperties": {
        "type": "object",
        "properties": {
          "max_count": { "type": "integer", "minimum": 0 },
          "window_seconds": { "type": "integer", "minimum": 1 }
        }
      }
    }
  }
}
```

#### 3.2.2 集成热更新流程

```
ConfigHotReloadService.apply_changes:
  1. compute_diff(old, new) → changed_keys
  2. ConfigSchemaValidator.validate_partial(new, changed_keys)
  3. If invalid → reject change, log error, keep old config
  4. If valid → apply_changes(new)
```

### 3.3 关键设计

- 使用 `jsonschema` 库（纯 Python，无 C 扩展）
- 默认 schema 内嵌于代码，可通过 `CONFIG_SCHEMA_PATH` 覆盖
- `validate_partial` 只校验变更字段，性能优
- 验证失败写入结构化日志，不影响现有逻辑
- 支持 Draft-07 JSON Schema 规范

### 3.4 验收标准

- [ ] JSON Schema 文件存在且格式正确
- [ ] `ConfigSchemaValidator.validate()` 对合法配置返回 valid=True
- [ ] `ConfigSchemaValidator.validate()` 对非法配置返回 valid=False + errors
- [ ] `validate_partial()` 只检查 changed_keys
- [ ] 集成到 ConfigHotReloadService 流程中
- [ ] AST parse 语法检查通过
