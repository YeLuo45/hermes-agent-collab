# Direction AL: 多语言 i18n 国际化框架

## 1. 目标

为 hermes-agent-collab 提供完整的 i18n 国际化框架，支持多语言切换（英文/中文/日文/韩文等），将所有 UI 文本、错误消息、通知内容外部化到语言包文件。

## 2. 背景

当前系统（Direction AK）支持知识图谱，但缺乏国际化能力。协作面板需要支持：
- 前端 dashboard 多语言切换
- API 错误消息多语言
- 通知内容模板多语言
- Agent 日志消息多语言

## 3. 功能范围

### 3.1 i18n 数据模型

```python
@dataclass
class LocaleInfo:
    code: str          # e.g., "en", "zh", "ja", "ko"
    name: str          # e.g., "English", "中文", "日本語", "한국어"
    native_name: str   # e.g., "English", "简体中文", "日本語", "한국어"
    is_rtl: bool       # Right-to-left language
    is_active: bool

@dataclass
class TranslationKey:
    key: str
    translations: dict[str, str]  # locale -> translation
    description: str = ""
```

### 3.2 核心组件

#### 3.2.1 I18nManager

```python
class I18nManager:
    """Manages locales, translations, and language switching."""
    
    def __init__(self, default_locale: str = "en"):
        self._locales: dict[str, LocaleInfo] = {}
        self._translations: dict[str, dict[str, str]] = {}  # locale -> key -> translation
        self._default_locale = default_locale
        self._current_locale = default_locale
    
    def add_locale(self, locale: LocaleInfo) -> bool:
        """Register a new locale."""
    
    def add_translations(self, locale: str, translations: dict[str, str]):
        """Add translation key-value pairs for a locale."""
    
    def get_translation(self, key: str, locale: str | None = None) -> str:
        """Get translation for a key. Falls back to default locale."""
    
    def set_locale(self, locale: str) -> bool:
        """Switch current locale."""
    
    def get_locale(self) -> str:
        """Get current locale code."""
    
    def get_available_locales(self) -> list[LocaleInfo]:
        """List all available locales."""
    
    def translate_template(self, template: str, **kwargs) -> str:
        """Translate a template string with variable interpolation."""
    
    def to_dict(self) -> dict:
        """Export all translations as dict."""
    
    def to_json(self) -> str:
        """Export all translations as JSON."""
```

#### 3.2.2 LocaleDetector

```python
class LocaleDetector:
    """Detects user preferred locale from Accept-Language header."""
    
    def detect(self, accept_language: str | None) -> str:
        """Detect locale from Accept-Language header."""
    
    def is_supported(self, locale: str) -> bool:
        """Check if locale is supported."""
```

### 3.3 内置语言包

- **en (English)**: 默认语言
- **zh (简体中文)**: 完整翻译
- **ja (日本語)**: 基础翻译
- **ko (한국어)**: 基础翻译

### 3.4 关键设计

- **单例模式**：`get_i18n_manager()` 全局访问点
- **变量插值**：支持 `{{name}}`, `{{count}}` 格式
- **回退机制**：未翻译键回退到默认语言（en）
- **懒加载**：支持按需加载语言包
- **RTL 支持**：可选 is_rtl 标记（未来希伯来语/阿拉伯语）
- **命名空间**：支持 `section.key` 分层键（e.g., `agent.status.running`）

### 3.5 API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/i18n/locales` | 列出可用语言 |
| GET | `/i18n/translations/{locale}` | 获取语言包 |
| POST | `/i18n/locales` | 注册新语言 |
| PUT | `/i18n/translations/{locale}` | 更新语言包 |
| PUT | `/i18n/locales/{locale}` | 设置当前语言 |
| GET | `/i18n/current` | 获取当前语言 |
| POST | `/i18n/translate` | 翻译模板 |
