# Direction AH: 通知管道（Slack/Email 异步通知）

## 1. 目标

为 hermes-agent-collab 提供可插拔的通知管道，支持 Slack、Email 等通知渠道，实现任务状态变更、Agent 协作事件、系统告警的异步通知。

## 2. 背景

当前系统（Direction AG）支持分布式追踪，但缺乏通知能力。协作场景中需要：
- 任务完成/失败时主动通知相关人员
- Agent 协作事件实时推送到 Slack
- 系统异常告警发送到 Email 或 Slack
- 支持多个通知渠道的组合

## 3. 功能范围

### 3.1 通知管道架构

```
Event Bus (Direction D)
    ↓
NotificationManager
    ├── SlackChannel ──────→ Slack Webhook / API
    ├── EmailChannel ──────→ SMTP / SendGrid
    ├── WebhookChannel ───→ Generic HTTP POST
    └── ConsoleChannel ────→ stdout (dev)
```

### 3.2 核心组件

#### 3.2.1 NotificationManager

```python
class NotificationManager:
    """Manages notification channels and routes events to appropriate channels."""
    
    def __init__(self):
        self._channels: dict[str, NotificationChannel] = {}
    
    def register_channel(self, name: str, channel: NotificationChannel):
        """Register a notification channel."""
    
    def send(self, event: NotificationEvent) -> dict[str, bool]:
        """Send notification to all registered channels. Returns delivery status per channel."""
    
    def send_to_channel(self, channel_name: str, event: NotificationEvent) -> bool:
        """Send notification to a specific channel."""
```

#### 3.2.2 NotificationEvent

```python
@dataclass
class NotificationEvent:
    """Standard notification event format."""
    id: str                    # UUID
    type: str                 # "task.completed", "agent.joined", "alert.error"
    title: str                # Short summary
    body: str                 # Detailed message
    severity: str             # "info", "warning", "error", "critical"
    source: str               # "hermes-agent-collab"
    workspace_id: str | None
    metadata: dict            # Additional context
    created_at: str           # ISO timestamp
```

#### 3.2.3 NotificationChannel 接口

```python
class NotificationChannel(ABC):
    """Abstract base class for notification channels."""
    
    @abstractmethod
    def send(self, event: NotificationEvent) -> bool:
        """Send notification. Returns True if sent successfully."""
    
    @abstractmethod
    def supports_severity(self, severity: str) -> bool:
        """Check if this channel supports the given severity level."""
```

#### 3.2.4 预实现渠道

| 渠道 | 说明 | 依赖 |
|------|------|------|
| `ConsoleChannel` | 打印到 stdout | — |
| `SlackChannel` | Slack Incoming Webhook | aiohttp |
| `EmailChannel` | SMTP 邮件发送 | smtplib (stdlib) |
| `WebhookChannel` | 通用 HTTP POST | aiohttp |

### 3.3 通知事件类型

| 事件类型 | 触发时机 | 渠道 |
|----------|----------|------|
| `task.created` | 新任务创建 | Slack, Email |
| `task.completed` | 任务完成 | Slack |
| `task.failed` | 任务失败 | Slack, Email |
| `agent.registered` | Agent 注册 | Slack |
| `agent.offline` | Agent 下线 | Slack |
| `collab.session_started` | 协作编辑开始 | Slack |
| `config.reloaded` | 配置热更新 | Slack |
| `alert.quota_exceeded` | 配额超限 | Email, Slack |
| `alert.error` | 系统错误 | Email, Slack |

### 3.4 通知配置（config.yaml）

```yaml
notifications:
  enabled: true
  default_channels: ["slack", "console"]
  channels:
    slack:
      type: slack
      webhook_url: "${SLACK_WEBHOOK_URL}"
      default_channel: "#hermes-alerts"
      severity_filter: ["warning", "error", "critical"]
    email:
      type: email
      smtp_host: "${SMTP_HOST}"
      smtp_port: 587
      smtp_user: "${SMTP_USER}"
      smtp_password: "${SMTP_PASSWORD}"
      from_address: "hermes@noreply.com"
      to_addresses: ["admin@example.com"]
      severity_filter: ["error", "critical"]
    console:
      type: console
      severity_filter: ["info", "warning", "error", "critical"]
```
