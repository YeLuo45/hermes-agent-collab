# Direction I: PostgreSQL 适配层

## 目标

为 hermes-agent-collab 添加 PostgreSQL 存储后端支持，补全三backend（JSON / SQLite / PostgreSQL）完整架构，提供异步连接池 + 事件驱动通知。

## 背景

当前 `storage.py` 已实现：
- `JsonFileStore`：fcntl 文件锁，JSON 文件，WAL 类并发
- `SQLiteStore`：WAL 模式，MVCC，MVCC-crash recovery，SQLite 事件表（append-only）

缺少 PostgreSQL 后端的场景：
- 多进程 / 多机器协作（SQLite 只适合单进程）
- 需要持久化历史事件（超过 SQLite 轻量级事件表容量）
- 高并发写入（PostgreSQL 连接池 >> SQLite 串性写入）
- 后续 Direction J（监控指标）需要时序数据能力

### PostgreSQL DDL Schema

每个 entity type 对应一张表，JSON 列使用 `JSONB` 类型（带 GIN 索引）：

```sql
-- agents
CREATE TABLE IF NOT EXISTS agents (
    agent_id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    role TEXT,
    status TEXT,
    system_prompt TEXT,
    capabilities JSONB DEFAULT '[]',
    metadata JSONB DEFAULT '{}',
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- tasks (带 GIN 索引支持 JSONB 查询)
CREATE TABLE IF NOT EXISTS tasks (
    task_id TEXT PRIMARY KEY,
    title TEXT NOT NULL,
    description TEXT,
    status TEXT,
    priority INTEGER,
    complexity TEXT,
    phase TEXT,
    phase_history JSONB DEFAULT '[]',
    assignee TEXT,
    depends_on JSONB DEFAULT '[]',
    blockers JSONB DEFAULT '[]',
    result TEXT,
    error TEXT,
    metadata JSONB DEFAULT '{}',
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW(),
    completed_at TIMESTAMPTZ
);
CREATE INDEX IF NOT EXISTS idx_tasks_status ON tasks(status);
CREATE INDEX IF NOT EXISTS idx_tasks_phase ON tasks(phase);
CREATE INDEX IF NOT EXISTS idx_tasks_metadata ON tasks USING GIN(metadata);

-- skills / workspaces / orchestrations / subtasks / reviews / messages / sessions / distributions
-- 类似结构（agent_id / task_id / workspace_id 等各自 PRIMARY KEY）
-- events (append-only, 时序)
CREATE TABLE IF NOT EXISTS events (
    event_id SERIAL PRIMARY KEY,
    event_type TEXT NOT NULL,
    payload JSONB NOT NULL,
    workspace_id TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX IF NOT EXISTS idx_events_type ON events(event_type);
CREATE INDEX IF NOT EXISTS idx_events_workspace ON events(workspace_id);
CREATE INDEX IF NOT EXISTS idx_events_created ON events(created_at DESC);
```

### 核心类设计

```python
# collaboration/postgres_storage.py

class PostgreSQLStore(StorageBackend):
    """PostgreSQL-backed async + sync storage.

    Uses asyncpg for async operations (FastAPI routes).
    Falls back to psycopg2 for sync operations (background tasks).
    Thread-local sync connection per thread.
    Connection pool (asyncpg) shared across instances.
    """

    # 连接管理
    _pools: dict[str, asyncpg.Pool] = {}  # shared across instances by dsn
    _sync_conns: dict[str, psycopg2.extensions.connection] = {}  # thread-local

    # Factory
    @classmethod
    def from_config(cls, workspace_path: Path, model_type: type[T],
                     json_filename: str, pg_config: dict) -> "PostgreSQLStore":
        dsn = build_dsn(pg_config)
        pool_size = pg_config.get("pool_size", 10)
        cls._ensure_pool(dsn, pool_size)
        table = TABLE_MAP[json_filename]
        return cls(dsn, model_type, table)

    # Async CRUD (for FastAPI)
    async def list_async(self) -> list[T]: ...
    async def get_async(self, key: str) -> T | None: ...
    async def upsert_async(self, entity: T) -> T: ...
    async def delete_async(self, key: str) -> bool: ...
    async def append_event_async(self, event_type: str, payload: dict, workspace_id: str) -> int: ...
    async def list_events_async(self, limit: int = 100, offset: int = 0, workspace_id: str = None) -> list[dict]: ...

    # Sync CRUD (for background tasks)
    def list(self) -> list[T]: ...
    def get(self, key: str) -> T | None: ...
    def upsert(self, entity: T) -> T: ...
    def delete(self, key: str) -> bool: ...

    # LISTEN/NOTIFY (event streaming)
    async def listen_async(self, channel: str, callback: Callable[[str, str], None]): ...
    async def notify_async(self, channel: str, payload: dict): ...
```

### 事件通知机制

PostgreSQL LISTEN/NOTIFY 替代 SSE：

```python
# 任务创建 → 通知所有订阅者
await pg_store.notify_async(f"workspace:{workspace_id}",
                             {"event": "task_created", "task_id": "t1"})

# FastAPI 端点 → 转换为 SSE
@app.get("/ws/{workspace_id}")
async def ws_events(workspace_id: str):
    async def event_generator():
        async with pg_store.listen_async(f"workspace:{workspace_id}",
                                         callback) as ch:
            async for msg in ch:
                yield f"data: {json.dumps(msg)}\n\n"
    return EventStreamResponse(event_generator())
```

### 迁移策略

不自动迁移数据。`PostgreSQLStore` 初始化时自动执行 `CREATE TABLE IF NOT EXISTS`（幂等），已有表不受影响。
