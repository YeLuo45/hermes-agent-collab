# P-20260518-009 PRD: CLI Tool + Python SDK (Direction H)

## 1. Overview

**Project**: hermes-agent-collab
**Proposal ID**: P-20260518-009
**Direction**: H
**Inspiration**: ruflo-design (CLI-first), generic-agent-design (SDK patterns)

## 2. Motivation

hermes-agent-collab A-G 完成了一套完整的 REST + SSE API，但：
- **无 CLI** — 开发者无法在终端管理 workspace/agent/task
- **无 Python SDK** — 其他 Python 项目无法 import 复用
- **无 WebSocket** — SSE 是单向，编排调试需要双向通信

Direction H 提供 CLI 工具和 Python SDK，让 hermes-agent-collab 可从终端驱动、可被其他项目 import。

## 3. Components

### 3.1 Python SDK (`hermes_agent_collab/`)

```
hermes_agent_collab/
  __init__.py          # exports HermesCollab, Config
  client.py            # HermesCollab class — thin REST client
  models.py            # Pydantic models mirroring API
  exceptions.py        # HermesCollabError, AuthError, NotFoundError
  websocket.py         # WebSocket client wrapper with auto-reconnect
```

**HermesCollab class**:
```python
from hermes_agent_collab import HermesCollab, Config

config = Config(api_key="ws1:sk_xxx", base_url="http://localhost:8000/api/collab/v1")
client = HermesCollab(config)

# Agents
agents = client.agents.list()
agent = client.agents.register(name="dev-agent", role="executor", skills=["python"])

# Tasks
task = client.tasks.create(title="Build API", priority="high")
task = client.tasks.get(task_id)

# Orchestrations
orch = client.orchestrations.create(title="Deploy Service", complexity="normal")
client.orchestrations.start(orch.orchestration_id)

# Events (SSE)
for event in client.events.stream():
    print(event)

# WebSocket
ws = client.websocket()
ws.send_message("hello", to="agent-1")
for msg in ws.messages():
    print(msg)
```

### 3.2 CLI Tool (`cli.py`)

Rich terminal UI (click + rich), single entrypoint `hermes-collab`:

```
hermes-collab agents list
hermes-collab agents register --name dev --role executor --skills python,bash
hermes-collab tasks create --title "Build API" --priority high
hermes-collab tasks list --status pending
hermes-collab orchestrations create --title "Deploy" --complexity normal
hermes-collab orchestrations start <orch_id>
hermes-collab events stream [--types agent.registered,task.completed]
hermes-collab workspaces create --id prod --name "Production"
hermes-collab workspaces list
hermes-collab auth create-key --name "ci-key" --workspace default --scopes read,write
hermes-collab auth list-keys
hermes-collab health
```

### 3.3 WebSocket Endpoint

Reuse existing `ChannelAdapter` from Direction A to provide bidirectional WebSocket communication at `/ws/{workspace_id}`.
