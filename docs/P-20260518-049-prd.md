# Direction AF: 实时协作编辑

## 1. 目标

为 hermes-agent-collab 提供实时协作编辑能力，支持多个用户同时编辑同一任务或策略，并通过 WebSocket 实时同步变更，配备 OT（Operational Transformation）冲突解决机制。

## 2. 背景

当前系统（Direction AE）支持工作流模板市场，但协作编辑仍依赖 REST API 的轮询模式。协作场景中需要：
- 实时同步：多人同时编辑同一资源，毫秒级延迟感知变更
- 冲突解决：OT 算法处理并发编辑冲突
-  Presence：显示当前在线用户和他们的编辑位置
-  Session 管理：编辑会话的创建、加入、离开

## 3. 功能范围

### 3.1 协作编辑 Session

```python
class CollabEditSession:
    """A real-time collaborative editing session."""
    session_id: str
    resource_type: str  # "task" | "strategy" | "workflow"
    resource_id: str
    version: int  # monotonic vector clock
    participants: dict[str, Participant]
    operations: list[Operation]  # operation log
    
class Participant:
    user_id: str
    cursor_position: dict  # field-level cursor
    selection: dict | None  # selected text range
    color: str  # assigned cursor color
    joined_at: str
    
class Operation:
    op_id: str
    user_id: str
    version: int
    op_type: str  # "insert" | "delete" | "replace"
    path: str  # JSON path to field
    value: Any  # new value (for insert/replace)
    old_value: Any  # old value (for delete/replace)
    timestamp: str
```

### 3.2 核心组件

#### 4.2.1 collab_edit_session.py

```python
class CollabEditSession:
    """WebSocket-based collaborative editing session."""
    
    def join(self, user_id: str, participant: Participant) -> JoinResponse:
        """Join a session."""
    
    def leave(self, user_id: str) -> None:
        """Leave a session."""
    
    def apply_operation(self, op: Operation) -> ApplyResponse:
        """Apply an operation and broadcast to all participants."""
    
    def get_state(self) -> SessionState:
        """Get current session state."""
    
    def can_undo(self, user_id: str) -> bool:
        """Check if user can undo."""
    
    def undo(self, user_id: str) -> Operation | None:
        """Undo last operation by user."""
```

def transform(op1: Operation, op2: Operation) -> tuple[Operation, Operation]:

class OTEngine:

#### 4.2.3 WebSocket 端点

```
WS /ws/collab/{resource_type}/{resource_id}
```

| 方向 | 载荷 | 说明 |
|------|------|------|
| client→server | `{"type": "join", "user_id": "...", "participant": {...}}` | 加入会话 |
| client→server | `{"type": "operation", "op": {...}}` | 提交操作 |
| client→server | `{"type": "leave"}` | 离开会话 |
| client→server | `{"type": "cursor", "position": {...}}` | 更新光标位置 |
| server→client | `{"type": "joined", "session": {...}, "participants": [...]}` | 加入确认 |
| server→client | `{"type": "operation_applied", "op": {...}, "version": N}` | 操作已应用 |
| server→client | `{"type": "participant_joined", "participant": {...}}` | 他人加入 |
| server→client | `{"type": "participant_left", "user_id": "..."}` | 他人离开 |
| server→client | `{"type": "cursor_update", "user_id": "...", "position": {...}}` | 光标更新 |
| server→client | `{"type": "conflict", "op": {...}, "transformed": {...}}` | 冲突提示 |

### 3.3 关键设计

- 存储：`~/.hermes/collab/sessions/` 目录存储活跃会话
- Session 超时：30 分钟无活动自动关闭
- OT 转换：pairwise OT（op1 vs op2），支持 insert/delete/replace
- 向后兼容：非 WebSocket 客户端仍可使用 REST API
